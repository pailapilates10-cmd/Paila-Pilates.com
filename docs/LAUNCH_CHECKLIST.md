# Before public launch

- [ ] Approve Paila's name treatment, story, brand assets, studio claims and photography.
- [ ] Approve studio address, opening hours, official email, phone and social links.
- [ ] Approve class names, times, locations, levels, instructors and booking capacity.
- [ ] Approve instructor bios and image use.
- [ ] Approve prices, taxes, validity, refunds and cancellation terms.
- [ ] Select and configure a real booking/payment service before enabling reservations or purchases.
- [ ] Select secure member services before collecting account, health or payment data.
- [ ] Publish only approved public data exports from the private operational Drive; check every file for private fields.
- [ ] Review mobile layout and accessibility with actual content.
- [ ] Choose hosting, domain and publication timing; remove draft banners and `noindex` after approval.

Source of project handoff: [Paila Drive handoff](https://docs.google.com/document/d/1kvb-cP3qWANfXyubWm6thOIRC7jBHPuttuledZks2Qs/edit). This checklist reflects the draft's current limits, not final business policies.
